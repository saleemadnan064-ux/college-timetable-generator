# College Timetable Generator

A Python-based desktop application for managing and generating college timetables.

## Features

- Manage teachers and subjects
- Manage classes, programs, and sections
- Assign teachers to subjects
- Generate class timetables
- Generate teacher timetables
- SQLite database support
- Bulk data management
- Timetable conflict checking
- PDF timetable generation
- Professional desktop GUI

## Technologies Used

- Python
- PyQt5
- SQLite
- ReportLab

## Purpose

This project was developed as a Python desktop application for learning and demonstrating GUI development, database management, timetable generation, and software development.
